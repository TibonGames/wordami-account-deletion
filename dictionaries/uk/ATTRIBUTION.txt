Modifications (made for the word game Wordami)
---------------------------------------------
File: uk_UAEdited.txt (inside uk_UAEdited.zip) - one word per line, UTF-8, lower case.
  1. All word forms were generated from uk_UA.dic using the affix rules in uk_UA.aff.
  2. Removed: proper nouns, abbreviations and acronyms, units, hyphenated forms,
     words with characters outside the Ukrainian alphabet, and offensive vocabulary.
  3. Apostrophes were removed from all words (e.g. "п'ять" -> "пять"), because the
     game ignores the apostrophe.
  4. Inside the game the list is converted into a binary search structure (trie);
     that file is generated automatically from uk_UAEdited.txt, which is the
     Source Code form of the Modifications.
