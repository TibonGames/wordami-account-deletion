Modifications (made for the word game Wordami)
---------------------------------------------
File: ro_ROEdited.txt (inside ro_ROEdited.zip) - one word per line, UTF-8, lower case.
  1. All word forms were generated from ro_RO.dic using the affix rules in ro_RO.aff
     (including the automatic prefixes re-, ne- and auto-).
  2. Letters ş/ţ (cedilla) were unified to ș/ț (comma below).
  3. Removed: proper nouns, abbreviations, acronyms and units, roman numerals,
     lower-case program names, hyphenated forms, words with digits or characters
     outside the Romanian alphabet, corrupt entries, forms produced by faulty affix
     rules (e.g. "draă" instead of "dragă") and offensive vocabulary.
  4. Inside the game the list is converted into a binary search structure (trie);
     that file is generated automatically from ro_ROEdited.txt, which is the
     Source Code form of the Modifications.
